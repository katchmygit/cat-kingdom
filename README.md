# 냥냥 삼총사: 독수리 왕국 대작전

고양이 3마리(그루, 루루, 모모)가 악당 독수리 대왕에 맞서는 게임풍 반응형 웹페이지입니다.

## 폴더 구조
```
cat-kingdom/
├─ index.html      페이지 구조(HTML)
├─ README.md
├─ css/style.css   디자인, 반응형, 애니메이션
├─ js/main.js      등장 연출, 클릭 동작, 캐릭터별 소리
├─ images/         gru.png, lulu.png, momo.png
└─ audio/          bgm.mp3 (배경음악), voice/ (캐릭터 목소리 mp3를 넣는 곳)
```

## 실행 방법
`index.html`을 브라우저(Chrome 등)로 열면 됩니다. 별도 설치는 필요 없어요.

## 수정 포인트
- 캐릭터 대사, 울음소리 높이, 목소리 톤: `js/main.js` 맨 위의 `C` 객체
- 색, 크기, 반응형 기준(760px): `css/style.css`
- 배경음악 교체: `audio/bgm.mp3`를 같은 이름으로 덮어쓰기 (볼륨은 `js/main.js`의 `vol()`)
- 캐릭터 이미지 교체: `images/` 안의 같은 이름 파일을 덮어쓰기

## 참고
- 폰트(Jua, Gowun Dodum)는 인터넷 연결이 있어야 불러와요. 연결이 없으면 기본 한글 폰트로 보여요.
- 목소리는 브라우저의 한국어 음성 기능을 사용해서 기기마다 느낌이 조금 달라요.
- 브라우저 정책상 화면을 한 번 누른 뒤부터 배경음악과 목소리가 나와요.
- 캐릭터가 말할 때는 배경음악이 잠깐 작아져요. 오른쪽 위 🎵 버튼으로 배경음악만 끌 수 있어요.

## 목소리 바꾸기
더 생동감 있는 목소리를 쓰려면 `audio/voice/README.txt`의 파일 이름과 연출 가이드대로 mp3를 만들어 그 폴더에 넣으세요. 파일이 있으면 그 목소리를, 없으면 브라우저 기본 음성을 써요.
